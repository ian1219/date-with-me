# date-with-me

A personal date invitation site. Open it on a phone and tap through the screens.

**Live site:** [https://ian1219.github.io/date-with-me/](https://ian1219.github.io/date-with-me/)

## Find this repo

On GitHub, search **date-with-me** under [ian1219](https://github.com/ian1219?tab=repositories).

## GitHub Pages

This is a static site (`index.html` at the repo root), so GitHub Pages can host it for free:

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save, then wait a minute and open the live site above
